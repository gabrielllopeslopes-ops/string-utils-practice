# String Utils

A tiny collection of string helper functions, built for practicing pull requests.

## Functions

- `reverse_string(text)` — returns the reversed string.
- `is_palindrome(text)` — checks if a string is a palindrome (case and space insensitive).
- `count_vowels(text)` — counts the number of vowels in a string.

## Running tests

```bash
pytest
```
